Try it without cloning.

With Python 3.11+, Git and uv installed, point your local MCP client at this pinned source command:

uvx --from git+https://github.com/vishalsachdev/uiuc-course-mcp@9778a866e6023bddfd41d6c8cf74e907f08ec106 uiuc-course-mcp

uv installs the server in an isolated cached environment. The command waits for an MCP client over stdio. See the copy-ready client configuration. For exact locked dependencies or development, use the local checkout below.

A small local setup.

1. Install

Requires Python 3.11+ and uv. Clone or download the repository, then run:

cd uiuc-course-mcp
uv sync --locked

The lockfile makes dependency installation reproducible.

2. Connect your client

Use the absolute executable path in your Claude Desktop configuration. On Windows, use .venv\Scripts\uiuc-course-mcp.exe.

{
  "mcpServers": {
    "uiuc-courses": {
      "command": "/ABSOLUTE/PATH/uiuc-course-mcp/.venv/bin/uiuc-course-mcp"
    }
  }
}

For Codex CLI:

codex mcp add uiuc-courses -- \
  /ABSOLUTE/PATH/uiuc-course-mcp/.venv/bin/uiuc-course-mcp

Restart your client after configuration. See the README for tool arguments, pagination and development commands.

This site is documentation, not an MCP endpoint. The server uses local stdio. Web and mobile remote connectors require a separately hosted service.

Official data.
Clear limits.

Data comes directly from Illinois Course Explorer. Each result includes its source URL, original retrieval time and cache age. No automatic cross-term fallback.

Search is scoped to one subject's offered course numbers and titles. This initial release does not perform semantic or campus-wide search.

Local by default

  • Five-minute memory cache; cleared on restart.
  • No telemetry, search-history storage or credentials.
  • No registration writes or student enrollment records.
  • Missing seat counts stay unknown. Status codes are not availability.
  • Source restrictions are preserved as prose; eligibility is not assessed.
